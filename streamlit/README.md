# Streamlit App Status

Last updated: 2026-07-14

This folder is currently a placeholder for a possible private coaching
dashboard. Coaches liked the Streamlit direction, but there is no active
`streamlit_app.py` in this repo right now.

The active app surface in this repo is:

- `backend/` — FastAPI API backed by Supabase
- `frontend/` — React dashboard and COUG Table views
- `pipeline/` — ingestion, scoring, scouting, and recruiting workflows

## Current Recommendation

Do not split new dashboard work across both Streamlit and React until the app
direction is decided. React/FastAPI is fine for the near-term private staff
surface if we add the right access controls and keep public/player-facing views
separate.

For near-term 2026 readiness, prioritize:

1. React/FastAPI season handling for active season `2026`
2. Private scouting dashboard/report viewer
3. Private player development dashboard
4. COUG Table score explainers and drilldowns
5. Scouting report Markdown outputs generated by `pipeline/scouting`
6. Recruiting similarity Markdown/CSV outputs generated by `pipeline/recruiting`

## Private Staff Surface

The private app requirements are:

- scouting and opposition preparation
- player development dashboard
- score explainers and player drilldowns
- recruiting similarity shortlists once data exists

These can be built in React/FastAPI or Streamlit. The important decision is to
avoid maintaining the same private workflow in both places.

The current React scaffold includes a staff tab with a local passcode gate. Set
the frontend environment variable below for local/private demos:

```text
VITE_STAFF_PASSCODE=<staff passcode>
```

This is a UI scaffold, not full production security. Before deployment, staff
API routes should also be protected server-side.

## If Streamlit Is Revived

Before using this folder again:

1. Add a real `streamlit_app.py`.
2. Move shared Supabase query code into one maintained module.
3. Avoid duplicating frontend-only COUG Table logic.
4. Add a README command that has been tested on a fresh clone.
5. Keep generated reports/data out of Git.

Until then, use this folder only as a parking place for Streamlit-specific
requirements or future notes.
